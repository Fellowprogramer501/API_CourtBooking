A project for managing data input by a user: Provides Login to the user,
When the user creates a booking, it checks for any bookings made at that time for that court, place, and sport; if not, it uploads the user's data to an SQL database.
The objects are linked through Django and are seen through the REST framework, and through Postman, the admin can manipulate the data
The registering user is also asked to verify himself as the user of the registering email.
The project is the second prototype of the original idea and is still under construction.
